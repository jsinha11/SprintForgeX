# AgileSprintSimulator

Small Java CLI app to simulate sprints, backlogs and velocity.

Build and run with Maven:

```bash
# compile and run unit tests
mvn test
```

If you want to run the app directly from source without Maven, use your IDE or compile the `src` tree.

Recommended branches:
- `feature/*` for new features
- `test/*` for tests
- `chore/*` for CI/docs

See CONTRIBUTING.md for PR workflow.
